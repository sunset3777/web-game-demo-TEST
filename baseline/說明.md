# 200 世基準說明

`基準_v7.json` 用固定種子（1～200）跑「預設」玩法：遇到事件一律選第一個選項。
`npm run baseline` 重新錄製，`npm run baseline:check` 跟基準比對。

## 重錄紀錄

- 2026-11-13：妖王徵兆與冒險一探。13 世不同（都是撞見妖王的那幾世）。
- 2026-11-17：作派三軸、正邪機緣、正道盤查與仇家。200 世全部不同。
  - v7 起，「一律選第一個」到金丹比例下降（21%→約 9.5%），原因是宗門指點一世封頂 2 次，屬預期，不是退步。
  - 歸因：宗門指點封頂、正邪機緣六則、仇家三者一起關掉時，到金丹回到 19%；隨機或依作派選擇的玩家到金丹比例沒有明顯下降。
